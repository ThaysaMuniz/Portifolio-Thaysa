# Portfólio Thaysa Muniz

Site estático simples para GitHub Pages.

## Arquivos
- `index.html`: página principal
- `style.css`: visual da página
- `portfolio-thaysa-muniz.pdf`: Media Kit/portfólio

## Publicar
1. Crie um repositório no GitHub.
2. Envie os 3 arquivos acima para a raiz do repositório.
3. Em Settings > Pages, selecione "Deploy from a branch".
4. Em Branch, escolha `main` e `/ (root)`.
5. Salve e aguarde o GitHub gerar o link público.
